# File Sharing System

A secure file-sharing system with a NestJS backend.

## 📁 Project Structure

- `backend/`: NestJS server with Prisma and Redis.
- `file_sharing_api.postman_collection.json`: Postman collection for API testing.

## 🚀 Getting Started

### Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Follow the instructions in the [backend/README.md](./backend/README.md) to set up and run the server.

## 🛠️ Main Features

- Secure user authentication.
- File upload and management.
- Real-time updates via WebSockets.
- Optimized performance with Redis caching.
- Automated email notifications.

## 🧪 Testing

The API can be tested using the provided Postman collection. Import `file_sharing_api.postman_collection.json` into Postman to see all available endpoints and their usage.
